# Веб-сайт MANHATTAN Club and Bar

Нічний клуб та бар **«MANHATTAN»** — навчальний вебпроєкт з дисципліни «Веб-орієнтовна розробка програмного забезпечення» (Лабораторні роботи №2 та №3).

Проєкт являє собою повноцінну багатосторінкову верстку сайту закладу із вбудованою панеллю адміністратора. Код розроблений відповідно до сучасних стандартів **HTML5** з дотриманням семантики, доступності та валідності за вимогами **W3C**. Оформлення виконано на **чистому CSS — без JavaScript**.

## Основний функціонал та особливості

- **Семантична структура**: `<header>`, `<nav>`, `<main>`, `<footer>`, `<section>`, `<article>`, `<figure>`, `<figcaption>`, `<aside>`.
- **Багатокрокове бронювання столиків**: форма з вибором дати та вільного часу на базі нативного **HTML5 Popover API**.
- **Інтерактивні модальні вікна**: опис подій на афіші, склад і ціни страв у меню, збільшені світлини в галереї.
- **Розгортання інформації без JS**: `<details>` та `<summary>` у розділах «Бенкети», «Туристи» та «Техрайдер».
- **Прихований вхід в адмін-панель**: невидима кнопка праворуч від логотипа відкриває вікно з логіном і паролем (макет форми, без серверної перевірки).
- **Панель адміністратора (`admin.html`)**: UI-прототип системи управління з дашбордом, таблицями замовлень, формами фільтрації, редагування цін, оновлення афіші та завантаження медіафайлів.
- **Доступність та валідність**: усі зображення мають `alt`, посилання — `href`, телефони — `tel:`, карта є зображенням-посиланням на Google Maps.

## Лабораторна робота №3: CSS, адаптивність, форми

### Застосовані технології

| Технологія | Де використано |
|---|---|
| **CSS Custom Properties** | Кольори, шрифти, радіуси й відступи з брендбуку — `css/base.css` (`:root`) |
| **Flexbox** | Шапка сайту, карусель страв (`scroll-snap`), блоки форм в адмін-панелі |
| **CSS Grid** | Hero + афіша, сітки меню / афіші / галереї, техрайдер, контакти, макет адмін-панелі |
| **Медіазапити `@media`** | Брейкпоінти `1180px` (бургер), `900px` (планшет), `600px` (телефон) |
| **Бургер-меню без JS** | Прихований `checkbox` + `label`, анімація розкриття через `grid-template-rows: 0fr → 1fr` |
| **Модальні вікна** | Стилізація `[popover]`, `::backdrop`, `@starting-style` (Popover API) |
| **Акордеон** | `<details>` / `<summary>` зі стрілкою на `::after` |
| **Валідація форм** | HTML5-атрибути (`required`, `pattern`, `minlength`, `min`/`max`) + стани `:user-invalid` / `:user-valid`, повідомлення про помилки через `::after` |
| **Організація стилів** | `style.css` підключає `base.css`, `layout.css`, `components.css` директивою `@import` |
| **Кросбраузерність** | `-webkit-` префікси (`backdrop-filter`, `appearance`), `@supports` для нових можливостей, запасні варіанти (`vh`/`dvh`) |

> Препроцесори Sass/Less не застосовувалися.

### Структура стилів

```
css/
├── style.css        — головний файл: шрифт + @import усіх інших
├── base.css         — змінні (брендбук), скидання, типографіка, посилання, списки, таблиці
├── layout.css       — каркас сторінок, Flexbox/Grid, медіазапити
└── components.css   — кнопки, форми та валідація, картки, акордеон, модальні вікна, адмін-таблиці
```

### Брендбук у стилях

- Кольори: `#210E09` (фон), `#D5621D` (акцент), `#FFFFFF` (текст); картки — акцент із прозорістю 5 %.
- Кнопки: помаранчева (основна) та біла (додаткова).
- Шрифт: Libre Franklin — Regular 400 та ExtraBold 800 (заголовки й акценти).

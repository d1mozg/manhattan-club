# Веб-сайт MANHATTAN Club and Bar

Нічний клуб та бар **«MANHATTAN»** — навчальний вебпроєкт, виконаний у межах Лабораторної роботи №2 з дисципліни «Веб-орієнтовна розробка програмного забезпечення». 

Проєкт являє собою повноцінну багатосторінкову верстку сайту закладу із вбудованою панеллю адміністратора. Код розроблений суворо відповідно до сучасних стандартів **HTML5** з дотриманням семантики, доступності та повної валідності за вимогами **W3C**.

## Основний функціонал та особливості

* **Семантична структура**: Використано елементи `<header>`, `<nav>`, `<main>`, `<footer>`, `<section>`, `<article>`, `<figure>`, `<figcaption>`, `<aside>`.
* **Багатокрокове бронювання столиків**: Форма збору даних із вибором дати та вільного часу на базі нового нативного **HTML5 Popover API**.
* **Інтерактивні модальні вікна**: 
  * Детальний опис подій та умов входу на сторінці афіші.
  * Перегляд складу та цін страв у меню.
  * Збільшений перегляд світлин у фотогалереї закладу.
* **Розгортання інформації без JS**: Використання елементів `<details>` та `<summary>` у розділах «Бенкети», «Туристи» та «Техрайдер».
* **Панель адміністратора (`admin.html`)**: UI-прототип системи управління з дашбордом статистики, таблицями замовлень, формами фільтрації, редагування цін, оновлення афіші та завантаження медіафайлів.
* **Доступність та валідність**: Усі зображення мають атрибути `alt`, посилання містять `href`, телефонні номери інтегровані через `tel:`, а карта в контактах є інтерактивним зображенням-посиланням на Google Maps.

## Структура проєкту

```text
MANHATTAN/
│
├── images/                  # Графічні ресурси сайту
│   ├── icon_manhetten.png   # Логотип закладу
│   ├── header_image.png     # Банер головної сторінки
│   ├── afisha1.png...       # Постери подій та концертів
│   ├── dish1.png...         # Фотографії страв та напоїв
│   ├── gallery1.png...      # Інтер'єрні фотографії галереї
│   ├── booking-preview.png  # Схема зали для бронювання
│   └── map.jpg / map.png    # Карта розташування закладу
│
├── index.html               # Головна сторінка (Hero, анонси, кухня, техрайдер, контакти)
├── menu.html                # Повне меню страв та напоїв за категоріями
├── affiche.html             # Афіша подій та концертів з опис-вікнами
├── why_us.html              # Інформація про фуршети, корпоративи та переваги
├── galery.html             # Фотогалерея інтер'єру та подій
├── admin.html               # Статичний UI-макет панелі адміністратора
└── README.md                # Документація проєкту
```
